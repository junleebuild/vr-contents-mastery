# Blender Beginner Course - Day 1 Summary

This is a summary of what I learned on Day 1 of the Blender Beginner Course.

---

## 🖥️ Scene and Viewport Basics

- The **Viewport** is the main window where you see and interact with your 3D scene.
- **Rotate View:** Hold the **Middle Mouse Button (MMB)** and drag.
- **Move 3D Cursor:** `Shift + Right Click` to place the **3D Cursor**, which sets the location for adding new objects.

---

## 🔧 Input Settings

- To enable the numpad on laptops or keyboards without a numpad:
  - Go to **Edit > Preferences > Input**  
  - Enable **Emulate Numpad**

---

## ➕ Adding Objects

- **Add Objects via Menu:**  
  - Go to the **Add** panel on the top menu.
- **Shortcut:**  
  - Press `Shift + A` to quickly add objects like meshes (cube, sphere, etc).

---

## 🔢 Useful Numpad Shortcuts

| Shortcut | Action |
|----------|--------|
| Numpad `5` | Toggle between **Perspective** and **Orthographic** view |
| Numpad `0` | Switch to **Camera View** |

### 📐 Perspective vs Orthographic

- **Perspective View:**  
  Objects appear smaller when they are farther away. This simulates how we see the real world.
- **Orthographic View:**  
  All objects appear the same size regardless of distance. Useful for technical modeling and aligning objects precisely.

---

## 🎛️ Object Manipulation

| Shortcut | Action |
|----------|--------|
| `G` | Grab (Move) |
| `X`, `Y`, `Z` | Move along **X**, **Y**, or **Z** axis |
| `S` | Scale |
| `N` | Open the **Item Properties** panel (position, rotation, scale info) |
| `Ctrl + 3` | Switch to **Reverse View** (quick rotate view to opposite side) |
